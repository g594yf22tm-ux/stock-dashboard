## 写作风格

1. **简洁有力** — 摘要部分读者只需 30 秒即可把握核心结论
2. **数据驱动** — 每个判断都有数据支撑，不空谈
3. **表格优先** — 关键数据用表格呈现，减少文字堆砌
4. **观点清晰** — 不模棱两可，明确给出判断和理由
5. **风险平衡** — 正面和负面因素都客观呈现

## 输出路径

```
reports/{股票代码}_{分析类型}_{YYYY-MM-DD}.md
```

示例:
- `reports/AAPL_deep_dive_2026-05-31.md`
- `reports/semiconductor_sector_scan_2026-05-31.md`
- `reports/portfolio_review_2026-05-31.md`
- `reports/NVDA_earnings_preview_2026-05-31.md`

## 约束

- 报告必须包含免责声明
- 所有数据必须注明来源和时间
- 估值数据和评分仅作参考，不得被视为投资建议
- 综合评分权重可根据分析类型调整（如财报预览中技术面权重可降低）
