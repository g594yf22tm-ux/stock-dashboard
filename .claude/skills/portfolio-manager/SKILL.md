# 持仓管理

## 触发
用户说：我的持仓、portfolio、仓位、持仓分析、仓位管理

## 流程

### 第1步：读取持仓数据
```
读取 dashboard/data/portfolio.json
解析：positions[], cash
```

### 第2步：获取实时行情
```
对每只持仓股票:
  读取 dashboard/data/watchlist.json 获取实时价格
  读取 dashboard/data/analysis.json 获取技术指标
```

### 第3步：计算组合指标
```
总资产 = 现金 + SUM(股数 × 现价)
总盈亏 = 总资产 - 总成本
收益率 = 总盈亏 / 总成本 × 100%
个股权重 = 个股市值 / 总资产 × 100%
行业集中度 = 按sector聚合权重
```

### 第4步：生成报告

```markdown
# 💼 持仓分析报告 — {日期}

## 📊 总览
| 指标 | 数值 |
|------|------|
| 总资产 | ¥XXX万 |
| 总成本 | ¥XXX万 |
| 总盈亏 | +¥X.XX万 (+XX%) |
| 持仓数 | X只 |
| 现金 | ¥X万 |

## 📋 个股明细
| 股票 | 持仓 | 成本 | 现价 | 盈亏 | 占比 | 信号 |
|------|------|------|------|------|------|------|

## ⚠️ 风险提示
- 行业集中度: {最高行业}占{X%}
- 最大单只占比: {股票}占{X%}
- 波动率加权: {X}%

## 💡 建议
- 需要再平衡? (权重偏离>5%)
- 止损建议 (亏损>10%)
- 止盈建议 (盈利>30%)
```
