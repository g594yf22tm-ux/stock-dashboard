# 每日盘前简报

## 触发
用户说：早报、盘前简报、今天市场怎么样、morning briefing、开盘前

## 流程

### 第1步：获取市场状态
```
data-engineer 代理 → 读取 dashboard/data/market.json
判断当前是盘前/盘中/盘后/周末
```

### 第2步：获取指数行情
```
yfinance get_market_summary → 美股三大指数
yfinance get_stock_price → ^GSPC, ^IXIC, ^HSI (标普/纳指/恒生)
新浪数据 → A股三大指数 (上证/深证/创业板)
```

### 第3步：获取关注列表
```
读取 dashboard/data/watchlist.json
每只股票: 价格/涨跌幅/信号/目标价/潜在空间
按涨跌幅排序 → Top3涨幅 + Top3跌幅
```

### 第4步：获取市场要闻
```
读取 dashboard/data/news.json
展示最新 5 条市场要闻
```
