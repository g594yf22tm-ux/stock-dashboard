# 多股对比

## 触发
用户说：对比XXX和YYY、compare、横向比较、PK

## 参数
- `stocks`: 股票代码列表，空格分隔，如 "600036.SS 600900.SS 000001.SZ"

## 流程

### 第1步：收集数据
```
每只股票:
  新浪数据 → 实时行情 (价格/涨跌幅/成交量)
  analysis.json → 技术指标 (RSI/MACD/MA/波动率/52周位置)
  watchlist.json → 目标价/潜在空间/信号
  yfinance → PE/PB/市值 (美股)
```

### 第2步：计算对比维度

| 维度 | 指标 |
|------|------|
| 估值 | PE / PB / 目标价空间 |
| 动量 | 涨跌幅 / RSI / MACD方向 |
| 趋势 | MA多空排列 / 52周位置 |
| 风险 | 波动率 / 量比 / 个股风险 |
| 综合 | 专家评分 / 建议信号 |

### 第3步：生成对比报告

