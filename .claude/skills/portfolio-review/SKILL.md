# 投资组合审查

评估投资组合的整体健康度，识别集中度风险，运行压力测试。

## 输入

- 如用户指定了持仓文件，读取该文件
- 否则读取 `portfolio/` 目录下最新的持仓数据
- 持仓格式: 每行一个持仓，格式 `{TICKER} {仓位占比}%` 或 JSON `[{"ticker": "AAPL", "weight": 15.5}]`

## 工作流程

### Step 1: 获取持仓数据
- 读取并解析持仓文件
- 验证仓位总和（应接近 100%，含现金则注明）
- 对每只持仓，使用 yfinance 获取当前价格和基本数据

### Step 2: 组合画像
- **行业分布**: 用 fmp `getCompanyProfile` 获取每只股票的行业，计算各行业占比
- **市值分布**: 大盘(>$100B) / 中盘($10-100B) / 小盘(<$10B)
- **地域分布**: 美股/A股/港股/其他
- **风格分布**: 价值型 / 成长型 / 混合型

### Step 3: 组合风险指标
计算以下关键指标：
- **HHI 行业集中度**: Σ(行业权重²)，>2500 = 集中，>4000 = 高度集中
- **最大单票仓位**: >15% = 警告
- **前5持仓占比**: >50% = 集中度偏高
- **加权平均贝塔**: 使用 yfinance 数据
- **组合波动率**: 基于历史收益计算
- **平均相关性**: 持仓间收益相关性矩阵

### Step 4: 压力测试
调用 `risk-manager` 子代理，对组合整体运行三种历史情景：
- 2008 金融危机
- 2020 疫情冲击
- 2022 加息周期

### Step 5: 绩效概览
- 组合 YTD / 1Y / 3Y 收益（如果可获取）
- 与基准对比（S&P 500 / 沪深300 / 恒生指数）
- 夏普比率和最大回撤

### Step 6: 生成报告
输出完整组合健康报告：
```markdown
## 💼 投资组合审查报告
**审查日期**: YYYY-MM-DD
**持仓数量**: X 只 | **总仓位**: Y%

### 组合画像
[行业/市值/地域/风格分布图表]

### 风险仪表盘
| 指标 | 当前值 | 阈值 | 状态 |
|------|--------|------|------|
| HHI | | 2500 | 🟢/🟡/🔴 |
| 最大单票 | | 15% | 🟢/🟡/🔴 |
| 前5集中度 | | 50% | 🟢/🟡/🔴 |
| 加权贝塔 | | 1.2 | 🟢/🟡/🔴 |

### 压力测试
[情景表格]

### 调仓建议（仅供参考）
- ⚠️ 减仓关注: [...]
- ✅ 维持: [...]
- 📈 增仓考虑: [...]
```

保存路径: `reports/portfolio_review_{YYYY-MM-DD}.md`

## 使用示例

```
用户: /portfolio-review
用户: /portfolio-review portfolio/my_holdings.json
用户: 检查我的投资组合有没有过度集中的问题
```

## 注意事项

- 组合分析基于提供的数据，不保证数据完整性
- 调仓建议仅从风险角度出发，不构成投资建议
- 如果持仓包含 A股，yfinance 的数据可能有限，标注数据覆盖率
