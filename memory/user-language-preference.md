用户要求 Claude Code 的所有回复、解释、错误消息、技能输出等都使用中文（简体中文）。不要使用英文，除非是代码、变量名、命令行参数等技术性不可翻译的内容。技术术语可以保留英文原文（如 API、CSS、JSON、npm 等），但解释和描述必须用中文。

**Why:** 用户更习惯阅读中文，英文阅读有障碍。

**How to apply:** 所有面向用户的输出使用中文。代码注释和文档同样使用中文。仅在代码本身、命令行参数、配置文件键名等技术必须保持英文的部分使用英文。
